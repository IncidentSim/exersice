# Каталог заданий

Этот каталог является самодостаточным источником заданий для `incidentctl`. Его можно хранить вместе с CLI или вынести в отдельный Git-репозиторий без изменения внутренней структуры.

## Структура

```text
exersice/
├── README.md
├── AGENTS.md
├── skills/
└── <exercise-name>/
    ├── vm.json
    ├── README.md
    ├── SOLUTION.md
    ├── apps/
    ├── infra/
    ├── incident/
    ├── verification/
    └── tips/
```

Заданием считается непосредственная дочерняя директория, содержащая `vm.json`. Поэтому `skills/` и другие служебные файлы не появляются в списке заданий.

`vm.json` задаёт имя, требования к VM и точки входа `infra`, `incident` и `verification`. Остальные правила создания и проверки заданий находятся в `AGENTS.md` и `skills/create-incident-exercise/`.

Для удалённого источника Git-репозиторий должен содержать этот каталог целиком: задания, `skills/`, `AGENTS.md` и `README.md`. Путь к каталогу задаётся полем `subdirectory` в конфигурации Git-источника.
