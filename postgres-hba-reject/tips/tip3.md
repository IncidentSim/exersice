# Подсказка 3. Порядок имеет значение

Правила `pg_hba.conf` просматриваются сверху вниз, и срабатывает первое подходящее — остальные уже не проверяются. После правки файла сервер нужно перечитать конфигурацию (`systemctl reload postgresql@16-main`). Не открывай доступ всем без пароля: вход с неверным паролем должен по-прежнему отклоняться.
