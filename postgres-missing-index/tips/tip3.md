# Подсказка 3. Чинить без простоя

Таймауты, `work_mem` и кэш ответов не меняют план запроса. Нужен способ находить строки клиента без чтения всей таблицы. Таблица в продакшене: обычный `CREATE INDEX` блокирует запись на всё время построения, а `CREATE INDEX CONCURRENTLY` — нет. После изменения обнови статистику.
